# 5.1 A light brief becomes one ticket

## Outcome
`/gates:grill <n>` triages the brief first: a light brief short-circuits to exactly one ticket through `kanban_ops.py new`, with no plan page and no Gate 1, and every full-lane ticket is stamped `lane: full`.

## Acceptance criteria
- AC-1 (behavioral): Given a brief whose named paths no charter `Applies to:` glob and no interface glob reach, which names no package, URL or env var and carries no partner-facing flag, When `triage.py <brief>` runs, Then it prints `light` with the four checks and their results and exits 0; Given any one check is true, Then it prints `full` and names the check that fired; Given a brief naming no path at all, Then it prints `full` (plan 5 AC-1)
- AC-2 (property): For all briefs, two runs of `triage.py` over the same brief, charter and interface globs print the same route, and the run makes no model call and no network call (plan 5 AC-2)
- AC-3 (behavioral): Given a brief that triages `light`, When `/gates:grill <n>` runs, Then no `kanban/plans/<n>.plan.md` is written, exactly one ticket `kanban/tickets/<n>.1.<slug>.md` exists carrying `lane: light`, `parent: <n>`, a `writes:` list of the paths the brief named and `## Acceptance criteria` holding `- AC-<n>` lines written from the brief's "What I want" in one tool-less, one-turn call, and the skill's last line is `Next: /gates:runner <n>.1`; a test pins the skill text (plan 5 AC-3)
- AC-4 (behavioral): Given a brief that triages `full`, When `/gates:grill <n>` runs, Then the grill runs as today — tree, questions, plan page, Gate 1 — and every ticket it writes carries `lane: full` (plan 5 AC-4)
- AC-5 (critical): Given any lane, When a ticket is created, Then it is created through `kanban_ops.py new <n> <slug> --body-file <path>`, which writes `kanban/tickets/<n>.<m>.<slug>.md` when the `.issues` marker is absent and creates the issue when it is present; no other code path writes a ticket file (plan 5 AC-5)

## Out of scope
- The diff budget and the over-budget stop — 5.2
- The lane record and the docs — 5.3
- A model call inside triage; the route stays a pure function
- Any change to the full lane's tree, questions, plan page, Gate 1 or routing stamp
