# 6.3 Findings group by identity, and a group is one typable line

## Outcome
Two findings are the same finding when their identity hash matches, never because their file
names match, and a group of them is disposed of in one Gate 2 line that names every id it covers.

## Acceptance criteria
- AC-1 (behavioral): Given two or more open findings with equal identity hashes, Then option A prints one collapsed line naming every id in the group and the earliest sighting, and one typable line `waive F2,F3,F5: <why>` covering the whole group (plan 6 AC-8).
- AC-2 (critical): Given a mechanical finding, Then its identity hash is over the emitting check, the path, the line and the normalised message, and a test asserts the hash is unchanged when the emitted `C<n>` number shifts because an earlier check fired.
- AC-3 (critical): Given a finding whose identity hash matches nothing in an earlier verdict, Then no code path recommends `waive` for it, and a test asserts a new finding in a previously flagged file is never grouped or waived on that fact alone (plan 6 AC-9).
- AC-4 (behavioral): Given `waive F2,F3,F5: <why>`, Then `kanban_ops.py` accepts the id list, records each id as waived with that reason, and `lint_kanban.addresses()` finds every one of them.
- AC-5 (critical): Given the 6.1 verdict as a fixture, Then C1 to C10 collapse to three groups keyed by host ticket, F3 stays open on its own, and no `child from` line is printed for any of them.
- AC-6 (property): For all verdicts, the identity lookup runs once per group rather than once per finding, and a test asserts the number of `traces/verdict/` reads does not grow with a group's size.
- AC-7 (behavioral): Given a single open finding whose identity matched an earlier verdict, Then its block still carries a `Second sighting:` line naming that verdict.

## Out of scope
- Unwrapping nested lint prose to find a shared innermost payload. Three groups is the correct
  reading of the current data; the findings-pipeline brief removes the nesting at source, and a
  parser for that format would be the only thing keeping it alive.
- A `drop` verb, or any new verb. 6.3 disposes of groups with the five that exist.
- Changing what `verdict_checks.py` emits, or what enters the packet.
- `seen_before`'s file-name match. It is replaced by the identity hash, not extended.
