# Glossary

One canonical name per concept. Identical in code, docs, tickets, conversation.

| Term | Meaning |
|---|---|
| Brief | Human-written intent, `kanban/briefs/`. Input to the grill. |
| Plan | Grill write-back, `kanban/<n>.plan.md`. Gate 1. |
| Ticket | One vertical slice. Gate 2 on its verdict. |
| Finding | Something noticed but out of scope; logged, never fixed in place. |
| Verdict | Fresh-context review result. `ship` or `reject`. |
| Domain pack | Everything domain-specific, `docs/domain-pack/`. |
